TropicPort — сайт для GitHub Pages
==================================
Вміст цього архіву = корінь сайта (index.html має лежати в корені репозиторію).

Як завантажити через GitHub Desktop:
1. На github.com створи НОВИЙ ПУБЛІЧНИЙ репозиторій з назвою: tropicport-ux.github.io
   (без README, без .gitignore — повністю порожній).
2. У GitHub Desktop: File -> Clone repository -> обери цей репозиторій.
3. Розпакуй цей архів і скопіюй ВСІ файли в папку клонованого репозиторію
   (index.html, assets, icon-288.png, tonconnect-manifest.json, .nojekyll).
4. GitHub Desktop покаже зміни -> внизу напиши "TropicPort site" -> Commit to main -> Push origin.
5. На github.com у репозиторії: Settings -> Pages -> Build and deployment ->
   Source: Deploy from a branch -> Branch: main, / (root) -> Save.
6. За ~1 хвилину сайт житиме на https://tropicport-ux.github.io/
   Скажи асистенту "готово" — він перемкне кнопку Market у боті на цю адресу.
